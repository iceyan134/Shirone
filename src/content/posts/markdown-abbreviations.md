缩写语法适合技术文章里的专有名词。你可以在文章末尾统一声明。

HTML、CSS 和 SSR 都是常见缩写。

*[HTML]: HyperText Markup Language
*[CSS]: Cascading Style Sheets
*[SSR]: Server-Side Rendering

## 写法

```markdown
HTML、CSS 和 SSR 都是常见缩写。

*[HTML]: HyperText Markup Language
*[CSS]: Cascading Style Sheets
*[SSR]: Server-Side Rendering
```

建议只给读者可能不熟悉的缩写加解释，避免页面到处都是提示。
